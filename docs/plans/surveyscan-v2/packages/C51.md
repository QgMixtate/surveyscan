# C51. Обследования сети в Web

Эпоха: E2 (добавлено 2026-11-13 по требованию пилота C34). Статус: planned. Зависимости: C19, C20, C21, C22, C31.

Входы: [D-13](../decisions/D13-discovery-policy.md), библиотеки C19–C22 (`internal/discovery`, `internal/presence`,
`internal/remote/*`), хранилище секретов интеграций C31.05, спецификация разделы 20 (DISC-01…), Scan/scan_job.
Проверить решения и claims по фактическому checkout; не считать предыдущую эпоху выполненной без evidence.

## C51.01 — Модель и API обследований
Работа: Подготовка и проектирование. Роль: Архитектор / Backend Go-разработчик.
- Результат: подсети (CIDR, площадка, сборщик, профиль), обследования (ручные/по расписанию), результаты;
  контракт OpenAPI; права (админ заводит, оператор запускает) и аудит по D-13.
- Проверка: scope не расширяется; ограничения /22, 50 проб/с, раз в час проверяются на сервере.
- База оценки: одна площадка, один сборщик, 2 подсети.
- Статус: planned; evidence отсутствует до исполнения.

## C51.02 — Встроить пробы в collector
Работа: Реализация. Роль: Backend Go-разработчик.
- Результат: collector получает задание обследования от центра, выполняет TCP/ARP/ICMP (CAP_NET_RAW) с лимитами,
  возвращает подписанные наблюдения (C20) — без правки конфигурации collector вручную.
- Проверка: адреса вне подсети отбрасываются; ICMP без CAP_NET_RAW — явная ошибка, не тишина.
- База оценки: тестовая сеть из 20 узлов (docker/netns).
- Статус: planned; evidence отсутствует до исполнения.

## C51.03 — Web «Обследования сети» и сбор из найденного
Работа: Реализация. Роль: Frontend / Backend.
- Результат: раздел Web — подсети, запуск/расписание, ход, результаты (найдено/новое/пропало/вернулось);
  «собирать по SSH/WinRM» с учёткой из OpenBao (ввод только в Web) и SNMPv3 для сетевых устройств.
- Проверка: учётки не видны в API/журналах; цель сбора создаётся без файлов на ВМ.
- База оценки: Linux, Windows и одно сетевое устройство в тестовой сети.
- Статус: planned; evidence отсутствует до исполнения.

## C51.04 — Проверить на стенде
Работа: Проверка и передача. Роль: Инженер проверки.
- Результат: обследование подсети стенда awm.local из Web, сбор из найденного, presence после выключения узла.
- Проверка: нет ложных склеек (замечание пилота №7), нагрузка проб в пределах D-13.
- База оценки: подсеть 10.170.108.0/24 стенда, по разрешению пользователя.
- Статус: planned; evidence отсутствует до исполнения.
