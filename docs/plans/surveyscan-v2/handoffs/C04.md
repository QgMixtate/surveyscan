## Запуск и устройство

[v2/README](../../../../v2/README.md), [workflow](../../../../.github/workflows/v2.yml).

```bash
cd /workspace/surveyscan/v2
export GOTOOLCHAIN=local
export GOROOT=/workspace/.surveyscan-v2-tools/go
export GOPATH=/workspace/.surveyscan-v2-tools/pkg
export GOCACHE=/workspace/.surveyscan-v2-tools/cache
make GO="$GOROOT/bin/go" CONTRACT_PYTHON=/workspace/.surveyscan-contract-tools/bin/python verify build
python3 scripts/dev.py up
make GO="$GOROOT/bin/go" integration
python3 scripts/smoke.py
```

`dev.py status/down/unseal`; `down` сохраняет тома. Стенд оставлен запущенным после smoke.
Loopback: PG 55432, Bao 58200, backend 58080, proxy 58081. Не публиковать адреса как production.
Секреты только в игнорируемом `.local/`, mode0700/0600; bootstrap root token не передаётся backend.
В архив/CI artifacts секреты, бинарники, caches и `.local/` не включать. One-share unseal, HTTP,
dev CREATEDB-role и single-node Bao допустимы только для этого локального стенда.

При проверке исправлены реальным запуском: file backend недоступен в выбранном Bao → обычный Raft;
initial init timeout увеличен; COPY executable permissions; writable nginx temp paths;
wget loopback healthcheck обходит proxy. Единственный новый пустой Bao volume пересоздавался после
оборванной первой инициализации без полученных ключей. PostgreSQL/v1/пользовательские данные не удалялись.
Автоматический `up` не сбрасывает ранее инициализированный storage при отсутствии unseal material.
