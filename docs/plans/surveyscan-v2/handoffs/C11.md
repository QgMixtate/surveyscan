## Реализация и проверка

Scoped OpenBao2.7.2 Raft: narrow policy, periodic token/renew/revoke/atomic operator replacement,
KV references и Transit non-exportable Ed25519 CA/receipt keys, root token rejection.
Pinned public metadata позволяет readonly startup при sealed Bao; readiness проверяет именно scoped identity.
No private-key fallback. Valid ingress/checkpoint держит raw staging до signed durable ACK;
dependency retries не расходуют data-error deadletter budget. Masked audit декларативен в Bao2.7.

Server C03 cert_renew challenge/proof/CSR binding, PG result ledger и source/revoke lock.
Exact retry возвращает прежний cert; wrong digest/domain/CSR/tenant/generation/expiry/revoke отвергаются.
Общий platform/machinecred Engine для агента/коллектора: pending key+CSR+proof0600 до network;
matching result+TLS private key одним atomic tls-identity.json0600, затем pending cleanup.
Исходные TLS files не удаляются; damaged/expired/symlink bundle не вызывает fallback.
Обычный renewal сохраняет origin signing key/source/generation/mapping/counters и pending inventory.

Collector config: source_id,credential_directory,signing_private_key_file (последние два вместе).
Credential state0700 отделён от spool, отдельный process lock исключает другого writer даже с иным
spool/listen. Cold refresh после lock устраняет старый cached credential. Listener/client TLS callbacks
читают один atomic pointer; hot reload закрывает старые idle outbound connections. CLIrenew и Run1h lead/
minute retry. deploy/collector.example.json — placeholder paths, установить private config0600.

Agent Prepare привязывает state к Linux /etc/machine-id через domain/source-bound HMAC под origin seed.
Raw id в binding не сохраняется. Mismatch/invalid/missing machine-id→отказ до новой отправки/sequence.
Pre-C11 enrolled state без binding не стартует; bind-host один раз после ручной проверки исходного
host/source/UID. Команда не заменяет несовпадающий binding. Golden image не содержит state/keys/machine-id.
ReadOptional использует Lstat, т.к. privatefile.Read скрывает os.ErrNotExist; symlink не принимается.

Новая SQL в этом продолжении не нужна:31migrations/42tables после0030. SQL0000–0030,C03/C09 bytes сохранены.
Legacy v1/connector не менялись. CI дополнили collector live test и sanitized report; hosted C11 unrun.

## Ограничения и следующий пакет

Identical machine-id+private keys неотличимы: нет hardware attestation/защиты от владельца keys/root.
Разные host IDs проверены unit matrix и copied mismatched fixture, реальная вторая VM unrun.
Expired cert fail-closed; automatic expired-identity reissue/continuity workflow ещё нет. Если действующего
bundle нет, остановить source, сохранить обе queues, проверить clock/network/Bao и привлечь оператора.
Новый admin grant/source не переносит старые pending/mapping автоматически; не править source/digest/counters.
Offline collector не обещает мгновенный отзыв сертификата. Old/new certs перекрываются до expiry;
backend source revoke закрывает дальнейший доступ обоих. Origin/center signing-key rotation не часть TLS renewal.
Production Bao HTTPS deployment/custody,systemd/24h/physical power loss/backup restore — C14/DR, unrun.

Далее C12: packages/C12.md. Минимальный user CLI поверх того же API (login/context/assets/sources/status),
не server console bootstrap и не обход tenant policy; потом versioned profiles и metrics/операторский сценарий.
Продолжать автоматически по R-019, не публиковать/сливать/деплоить без соответствующего поручения.
