## Важные решения для C04

- JSON Schema 2020-12, OpenAPI 3.1; строго объявленная версия 1.0, minor не принимается автоматически.
  Origin source/generation/namespace сохраняются по C02, sequence/version — десятичные uint64 strings.
- SHA256 JCS RFC8785(payload), Ed25519 domain-separated подписи observation/heartbeat/renewal/center result.
  Origin signing key bound к регистрации; не брать ключ из недоверенного payload. Full portable crypto — C23.
- Collector/center transport receipt не разрешает удаление spool. Только проверенный signed center result
  со всеми batch/tenant/origin/observation/digest bindings и durable disposition разрешает trim.
- Pending identity conflict сохраняется целиком на центре, получает recorded_pending_resolution и
  completed_with_errors; может освободить source spool после подписанного центрального подтверждения,
  но не называется применённой карточкой. Rejected сохраняется локально/quarantine, без автоудаления.
- Heartbeat challenge issued центром, source/generation/purpose bound, TTL 120s. Точный повтор
  принятого heartbeat возвращает старый accepted timestamp, не обновляя контакт. Renew требует
  доказательства действующим origin key, heartbeat nonce для renewal непригоден.
- Enrollment grant заранее bound к SHA256 DER CSR и origin public key; relay не подменяет ключи.
  Certificate renewal сохраняет generation/mapping; reset generation — отдельная явная операция.
- Jobs: claim_id/dedup, attempt/version/token fencing, lease expiry и cancel intent. После cancel_requested
  нет переочередивания или незаметного completed; commit/revision определяет победителя гонки.
- Event/checkpoint: at-least-once, один primary event на aggregate version, replay без автоматического
  повторения внешних действий. Реальная атомарность/конкуренция ещё не доказана.
