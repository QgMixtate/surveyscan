## Воспроизведение

```bash
export GOROOT=/workspace/.surveyscan-v2-tools/go
export GOPATH=/workspace/.surveyscan-v2-tools/pkg
export GOCACHE=/workspace/.surveyscan-v2-tools/cache
export GOTOOLCHAIN=local
cd /workspace/surveyscan/v2
make GO="$GOROOT/bin/go" CONTRACT_PYTHON=/workspace/.surveyscan-contract-tools/bin/python verify build
python3 scripts/dev.py up
make GO="$GOROOT/bin/go" integration
python3 scripts/smoke.py
python3 scripts/auth_smoke.py
```

Standalone serve требует SURVEYSCAN_V2_PUBLIC_ORIGIN; HTTPS default. Local HTTP — только с явным
INSECURE_LOCAL_HTTP=1 и loopback origin. В Compose эти dev-only настройки уже заданы.
Консоль читает private password file, не argv/password env. Bootstrap runtime user не создаётся автоматически;
smoke создаёт его только во временной тестовой БД. Не публиковать v2/.local, Bao bootstrap, logs или binaries.

## Далее C06

[C06](../packages/C06.md): постоянный реестр, история/outbox и реальные доменные handlers.
Входы: C02 модель, C03 contracts, C04 миграции, C05 access/port и app/http.go policy registry.
Новые handlers обязаны использовать tenant из проверенного principal и повторно Authorize в write transaction.
Job/artifact context должен иметь доверенное происхождение; credential ID не является публичным bearer.
Не обходить guards ownership/immutability/responsibility и не переписывать applied SQL.
C06 в текущем запросе не реализовывался. Прогресс: C01–C05 done, 20/200; 180 planned.
При финальном ревью отдельным тестом воспроизведён обратный lock order при одновременном
отзыве credentials и Authorize. Исправлено: сначала user lock, затем credential; после ожидания
проверки повторяются. Новый тест до исправления failed, после исправления passed; полный suite повторён.

Открытый внешний blocker текущего запроса: наблюдение hosted CI после применения сетевого allowlist.
