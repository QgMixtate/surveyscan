- collector в CI не поднимается (`collector_url` = collector.invalid); служба доходит только до Open.

## Критерии приёмки при возврате
По одному реальному/VM стенду на профиль прав; для каждой строки V1–V9 — факт (команда, SHA бинарника, результат, ресурсы), не mock;
провалы остаются в журнале. До этого C15.02/03/04 остаются in_progress/planned.
