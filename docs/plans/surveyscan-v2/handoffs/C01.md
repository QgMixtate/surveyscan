## Решения и ограничения

Подтверждено пользователем: Go-направление, постоянный local agent → collector,
отдельный Web UI, OpenBao, постоянный реестр/UID/ответственность, outbox без шины,
компактный SMB с расширением по эпохам и исходный порядок пакетов.

Инженерные defaults, не пользовательское утверждение каждой детали: Go 1.27.3,
PostgreSQL 17.x, Bao 2.7.2, bbolt 1.5.0 для spool, React/TS/Vite для Web, новое дерево `v2/`.
Go/registry/tag metadata прочитаны, артефакты и совместимость этими запросами не проверены.
Auth/session/enrollment/mTLS варианты описаны, детали протокола — C03/C05/C11.

Серверный dev-профиль Linux/amd64 Debian 13. **Первая ОС агента остаётся proposed** до C08:
ответ пользователя касался порядка плана, а не утверждения Windows/Linux agent OS.
Это не блокирует C02–C07. Доступ к полноценному host/VM, reboot и service manager
нужен для приёмки C08/C13/C14; managed shell не доказывает эти возможности.
