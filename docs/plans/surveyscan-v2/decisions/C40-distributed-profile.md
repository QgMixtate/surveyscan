Те же данные и сценарий, что C30/C35 (паспорт C30-load-passport: 2 001 актив, 100 пользователей, 100 виртуальных
пользователей, 300 с замера после 60 с разогрева, фоновый импорт). Топология: surveyscan-router (каталог C37) → 2 api
(C35, по кругу) → PostgreSQL; отдельный worker; сервис поиска. Один хост песочницы.

Все SLO паспорта выполнены. Найдено при прогоне: api без machine.json тихо деградирует до перебора по PostgreSQL
(p95 7,5 с, таймауты поиска) — правило «каждому api своя копия machine.json» внесено в OPERATIONS.md.

ячеек одновременно под нагрузкой.
