# C17.01 — профиль безагентного SSH-сбора Linux (проект, реализован в internal/remote/sshlinux)

Статус: проектное решение + локальная реализация (C17.03 частично). Живая цель и Bao-выдача (C17.02/04) — не выполнены.

- **Ключ хоста.** Обязателен, формат `SHA256:…` (как `ssh-keygen -lf`). Пустой → отказ ДО любого соединения; несовпадение →
  отказ без повторов. TOFU запрещён. `FetchHostKey` только показывает отпечаток оператору (без аутентификации, без команд);
  доверие — отдельное решение оператора вне канала.
- **Секрет.** Один способ: пароль ИЛИ приватный ключ (+passphrase). Живёт в памяти вызова; `Secret` печатается/маршалится как
  `[redacted]`; ошибки разбора ключа не содержат исходный текст. В argv/логи/результаты не попадает. Выдача из Bao scoped — C17.02.
- **Попытки.** Повторы только на сетевые сбои (≤3, по умолчанию 1). Отказ аутентификации не повторяется (риск блокировки УЗ).
- **Сроки.** Рукопожатие 10 с, команда 20 с, весь сбор 2 мин, вывод ≤16 МиБ на команду; отмена контекста закрывает соединение,
  собранные секции возвращаются как частичный результат вместе с причиной.
- **Права и команды.** Обычный пользователь без sudo (sudo -n — отдельное решение). Только фиксированные константы пакета:
  `cat` файлов /proc,/etc,/sys,/var/lib/dpkg,/lib/apk, `systemctl list-*`, `rpm -qa`; данные цели в командную строку не подставляются,
  PTY не запрашивается. Конфигурация цели не меняется. Парсеры общие с локальным агентом (linuxinventory).
- **Контракт.** Секции hardware/software/services/users_groups/resources/routes_ports, всегда `partial` (reason `REMOTE_SSH_PARTIAL`)
  или unavailable/unsupported; identity/os/network/updates/protection/neighbors и привязка к source/collector — следующий шаг.
- **Не проверено:** реальный sshd (OpenSSH), ключевая аутентификация на живой цели, ограниченные права (нет чтения product_serial/uuid),
  sudo, Bao, нагрузка, Debian/RHEL/Alpine. Тесты идут на настоящем SSH-протоколе (in-process сервер), но это не живая цель.
