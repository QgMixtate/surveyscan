# C33.01 — платформы и версии: что поддерживается (только проверенное)

Статус: предложено (R-027, 2026-11-12). Правило: **«поддерживается» — только то, что проверено живьём**;
проверенное только в CI/песочнице — «проверено в CI»; остальное — «не проверено» (не обещается).

## Уровни
- **Поддерживается** — живой прогон на стенде пользователя (сборка, установка, работа, перезапуск), есть протокол.
- **Проверено в CI/песочнице** — автоматические проверки на этой платформе, живого стенда нет.
- **Не проверено** — может работать, но не заявляется; заявление — только после прогона по C33.04.

## Сроки совместимости (предложение)
- Версия релиза — одна для сервера, агентов, collector, CLI и Web (`release.py` проверяет одну ревизию).
- Агент и collector на одну минорную версию старше/младше центра принимаются (C03 1.x, профиль 1.2); старше —
  только после обновления центра. Схема БД — только дописывается; откат — восстановлением из резервной копии (UPDATE.md).
- Поддержка версии зависимостей: PostgreSQL и OpenBao — до конца их апстрим-поддержки, обновление — минорными
  выпусками с повтором смоков upgrade/backup; Go — текущая и предыдущая минорные (сборка закреплена одной).

## Что нужно, чтобы расширить «поддерживается»
Прогон по C33.04 на чистой ВМ для каждой пары (ОС, роль): установка → сбор → обновление → резервная копия →
восстановление. Первые кандидаты (решение пользователя): Windows 10/11 и Server 2022 для агента; Astra Linux / RED
OS для агента и центра, если они есть у заказчиков.
