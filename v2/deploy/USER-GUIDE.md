# SurveyScan — руководство пользователя (оператор)

Для операторов и администраторов, работающих в Web. Установка и сопровождение — в [OPERATIONS.md](OPERATIONS.md).

## Вход
Откройте адрес SurveyScan в браузере, войдите своей учёткой. Сессия живёт 8 часов; одновременно — не больше 5
сессий одного пользователя (новый вход закрывает самую старую). Кнопка «Выйти» — справа вверху.

## 1. Найти актив
- **Поиск (00)** — по имени, IP, ПО, ОС, словоформам («сервера бухгалтерии»). Если сверху красная плашка
  «Полнотекстовый поиск недоступен» — ищется только точное совпадение, это не ошибка данных.
- **Реестр активов (01)** — список с фильтром по свежести; стрелка ↗ открывает карточку.

## 2. Карточка актива
- **Свежесть:** «Актуальные» — данные не старше суток; «Устаревшие» — источник давно не присылал данные;
  «Нет сведений» — время сбора не подтверждено. Контакт источника ≠ свежий сбор.
- Вкладки: факты инвентаризации (ОС, сеть, оборудование, службы, пользователи), **ПО**, **CMDB** (класс актива,
  связи с сервисами), **Ответственность** (кто отвечает и история передач).
- Бизнес-поля (имя, назначение, критичность, теги) правит оператор; сбор их не меняет.

## 3. Ответственность
- **Мои задачи (05):** «На мне», «На моих командах», «Не распределено» (у резервной команды площадки),
  «Требует передачи» (ответственный выбыл или отключён).
- Назначить: отметить активы → «Назначить на» → человек или команда → «Назначить выбранным». Если кто-то изменил
  актив одновременно с вами, такие строки не меняются — обновите список и повторите.
- Уволенный сотрудник (отключён в AD) — его активы автоматически переходят резервной команде площадки.

## 4. Разбор конфликтов (04)
Записи источников, которые нельзя однозначно сопоставить с активом (например, клон ВМ с тем же ID). Решение —
«Подтвердить» (это тот же актив), «Новый актив» или «Отклонить». Слияние и разделение карточек — в карточке актива.

## 5. Обмен с Excel / 1С (в реестре)
«Выгрузить CSV» → правка имени, назначения, критичности, тегов, класса в Excel → «Выбрать файл…» → **«Проверить»**
(ничего не меняет, показывает итог по строкам) → «Применить». Строка не применяется, если карточку изменили после
выгрузки — выгрузите заново. Пустая ячейка — не менять; «-» в классе — снять.

## 6. Поиск ПО (07) и схема сети (03)
«Поиск ПО» — где установлена программа и какие версии. «Схема сети» строится по адресам и маршрутам из
инвентаризации, без опроса сети; связи «вероятная»/«слабая» — это догадка, не факт.

## Администратор
- **Источники данных (02):** регистрация агента/collector/portable, профиль сбора (интервалы).
- **Оргструктура (08):** люди и команды; «Настроить подключение к AD» — адрес `ldaps://<имя контроллера>:636`
  (имя, не IP: сертификат выписан на имя), base DN, учётка **только на чтение**, пароль (хранится в OpenBao и
  больше не показывается), сертификат CA → «Проверить подключение» → «Сохранить». Люди из AD отмечены «AD» и
  правятся только в AD.
- **Уведомления (09):** «Включить уведомления» → адрес получателя (https) и события → секрет подписи показывается
  **один раз** — передайте его владельцу системы-получателя. «Доставки» — что ушло, что повторяется, «Повторить».
- Копии, обновления, сбои — [OPERATIONS.md](OPERATIONS.md).
